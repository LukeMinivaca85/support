Perguntas Frequentes

Como posso criar uma conta Lukintosh?

Você pode criar uma conta acessando accounts.lukintosh.com e seguindo as instruções de cadastro.

Como faço para baixar jogos no Lukintosh Store?

Após criar sua conta, acesse store.lukintosh.com, faça login e escolha o jogo que deseja baixar.

Posso usar a Lukintosh Play Engine para criar jogos comerciais?

Sim! A Lukintosh Play Engine é totalmente liberada para uso comercial e pessoal. Consulte nossa documentação para detalhes de licença.
